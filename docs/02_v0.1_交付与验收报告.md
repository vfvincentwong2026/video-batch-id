## 四、已知限制（诚实清单）

1. **生成是 mock**：产出 `mock://` 伪引用与描述，不产真实视频。接真实 provider（ComfyUI/Wan2.2 或视频 API）只需实现 `VariantGeneratorProvider` 接口。
2. **守卫是启发式**：v0.1 用于打通链路；真实 CLIP+GroundingDINO / pHash+Chromaprint 需 GPU，后置 v0.2。
3. **解析是 mock**：固定 4 镜头结构。真实 VLM（Qwen2.5-VL API 路线）同接口接入。
4. **变体数上限 = 组合空间**：请求超出时按空间产出并在 UI 提示（README 语义）。
5. **检索是 LIKE**：FTS5/pgvector 后置，接口已预留。
6. **Windows 路径**：静态服务已做目录穿越防护；未跑 Linux 验证。
7. **上传只登记元信息**：文件本体存储（本地磁盘 + Tunnel 回传）未实现。

## 五、v0.2 建议优先级（PM 排期建议）

1. **真实解析 provider**（云端 VLM API）——让你的真实素材进系统（等你把素材放进 `assets/incoming/`）
2. **真实生成 provider 二选一**：云 GPU（RunPod + ComfyUI + Wan2.2，单条 ~$0.01）或视频 API（快、贵 10-50 倍）
